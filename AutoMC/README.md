# AutoMC v1.1.0 — 项目式自动化

1.12.2 Forge 纯客户端 mod。**F8** 开关界面。项目 = 一串「事件 / 动作」积木，事件任一命中即运行。

## 安装

1. 删掉旧 jar：`自动指令-1.2.0.jar`、`自动拾取-2.2.jar`、更早的 `automc-*.jar`
2. `automc-1.1.0.jar` 放进 mods
3. 配置：`config/automc.json`（首次启动生成；旧 `autocommandzh.json` / `endframe.json` 会自动迁移）

## 结构

```
项目（可开关）
└─ 积木列表
   ├─ 事件块（进服 / 死亡 / 定时 / 血量低于…）→ 任一命中即启动项目
   └─ 动作块（发送聊天 / 延迟 / 循环 / 走路 / 交易…）→ 按行号顺序执行
```

## 事件（20 种）

进服、死亡、复活、定时、血量低于、饥饿低于、背包物品、背包满、经验等级、切换维度、受伤、聊天含关键词、附近掉落物、附近玩家、到达坐标、Y低于、游戏时间、手持变化、耐久偏低、手动。

## 动作（36 种）

| 分类 | 动作 |
|---|---|
| 消息 | 发送聊天、发送指令、提示自己 |
| 流程 | 延迟、随机延迟、循环开始、循环结束、跳转、条件跳转、等待条件、变量设置、变量运算、结束脚本 |
| 交互 | 右键、左键、长按右键、长按左键、攻击最近实体、NPC交易 |
| 移动 | 捡掉落物、走到方块、走到坐标、前进、停止移动、跳跃、潜行、疾跑 |
| 物品 | 切换快捷栏、丢弃手中、使用手中物品 |
| 视角 | 转向、看向最近玩家 |
| 系统 | 打开背包、关闭界面、按键、复制到剪贴板 |

条件写法：`血量<10`、`饥饿<=6`、`经验>=30`、`y<0`、`时间>=13000`、`物品:diamond>=64`、`变量:count>=3`、`距离:100,64,200<=5`

## 界面

- **项目列表**：卡片显示 名称 / 事件摘要 / 动作数 / 已开启状态；右侧「开关 · 运行」；点卡片选中
- **底部栏**：新建项目、编辑、⚙ 设置、⋯ 更多（复制所选 / 删除所选）、保存并退出
- **编辑器**：返回、项目名、已开启开关、积木行（分类色条 + 行内 ↑↓ + 单独开关）、参数面板、工具条（＋添加 / 复制 / 删除 / ▶测试 / 完成）
- **添加积木**：9 个分类页签（全部/事件/消息/流程/交互/移动/物品/视角/系统）
- **⚙ 设置**：透明度 35–100%、8 种强调色（蓝绿紫橙青粉黑灰）、预览、恢复默认

## 指令

`/amc gui` 打开界面 · `/amc run <序号|项目名>` · `/amc list` · `/amc stop` · `/amc status` · `/amc vars` · `/amc npc` · `/amc slot`
