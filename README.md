# AutoMC

**Minecraft 1.12.2 · Forge 客户端模组 · 把「一串操作」做成可复用的自动化项目**

按一下按键，自动发指令、自动走路、自动交易、自动交任务——不用记命令，不用写脚本，像搭积木一样把动作排成一条流程。

![界面预览](images/preview-list.png)

---

## 它是什么

AutoMC 是一个**纯客户端**的自动化模组。一个「项目」= 一串按顺序执行的动作；项目可以被事件触发（进服、定时、血量低于…），也可以绑一个按键手动触发。

```
项目：自动交易
├─ 右键            ← 打开面前 NPC 的商店
├─ 延迟 1000ms
├─ NPC交易         ← 在已打开的界面里，把背包里的物品换成指定商品
├─ 延迟 500ms
└─ ESC             ← 关掉界面（按键动作）
```

- **不改服务端、不发额外封包**，所有操作都是模拟你本人在点鼠标/敲键盘
- 支持条件判断、变量、循环、跳转，能做稍微复杂的逻辑
- 界面全自绘，支持半透明与主题色，低分辨率窗口自动切紧凑布局

---

## 功能一览

| 模块 | 说明 |
|---|---|
| 项目列表 | 卡片式管理，每个项目可单独启用/禁用、绑定按键、运行 |
| 动作编辑 | 36 种动作，7 个分类，拖行内 ↑↓ 排序，可单独禁用某一行动作 |
| 事件触发 | 20 种事件，进服/定时/血量/背包/坐标/聊天关键词…任一命中即启动项目 |
| 条件与变量 | `血量<10`、`物品:diamond>=64`、`变量:n>=3`、`距离:x,y,z<=5` 之类的表达式 |
| NPC 交易 | 打开商人界面后，把背包里的材料换成第 N 件商品，直到交完或换够 |
| 按键绑定 | 每个项目绑一个键，游戏里按一下即执行 |
| 界面设置 | 不透明度 35–100%、8 种主题色（蓝绿紫橙青粉黑灰）、实时预览 |

## 安装

1. 安装 **Minecraft 1.12.2** + **Forge 14.23.5.2847**（OptiFine 可选）
2. 把 `automc-x.y.z.jar` 放进 `.minecraft/mods/`
3. 启动游戏，进世界后按 **F8** 打开界面

> 纯客户端模组，服务器不需要安装；配置文件在 `config/automc.json`。

---

## 三分钟上手

1. **F8** 打开列表 → 点「＋ 新建项目」
2. 在编辑器里点「＋ 添加动作」，选一个动作（比如「发送指令」），在底部参数区填内容
3. 回到列表，点卡片右侧「开关」启用，再点「运行」——或者给它绑一个按键

需要「进服就自动跑」的话，在动作列表最上面加一条事件（如「进服」），事件命中时整个项目会自动启动。

---

## 事件（20 种）

| 事件 | 触发条件 |
|---|---|
| 进服 / 死亡 / 复活 | 进入世界、血量归零、重生 |
| 定时 | 每 N 秒 |
| 血量低于 / 饥饿低于 | 数值阈值 |
| 背包物品 / 背包满 | 指定物品达到数量 / 36 格全满 |
| 经验等级 | 达到等级 |
| 切换维度 / 受伤 / 手持变化 | 状态变化时 |
| 聊天含关键词 | 收到含指定词的聊天 |
| 附近掉落物 / 附近玩家 | 范围内出现目标 |
| 到达坐标 / Y 低于 | 位置条件 |
| 游戏时间 | 游戏内时刻（如 13000 夜晚） |
| 耐久偏低 | 手持物品耐久低于百分比 |
| 手动 | 不自动触发，只能手动运行 |

---

## 动作（36 种）

**消息**：发送聊天、发送指令、提示自己
**流程**：延迟、随机延迟、循环开始、循环结束、跳转、条件跳转、等待条件、变量设置、变量运算、结束脚本
**交互**：右键、左键、长按右键、长按左键、攻击最近实体、NPC交易
**移动**：捡掉落物、走到方块、走到坐标、前进、停止移动、跳跃、潜行、疾跑
**物品**：切换快捷栏、丢弃手中、使用手中物品
**视角**：转向、看向最近玩家
**系统**：打开背包、关闭界面、按键、复制到剪贴板

### NPC 交易怎么用

先放一个「右键」动作把 NPC 商店打开，再放「NPC交易」：

| 参数 | 选项 |
|---|---|
| 交出物品 | `背包物品`（自动从商人配方里挑一个你背包里有的）／ `指定ID`（填 `gold_ingot` 这类物品 id） |
| 交出数量 | `全部` ／ `指定数量` |
| 换取第几件 | 该物品能换的第 1～5 件商品 |

动作会循环执行「把材料 shift 点进商店输入槽 → 把产出 shift 点回背包」，直到材料用完或达到数量。

## 条件表达式

用在「条件跳转」「等待条件」里：

```
血量<10          饥饿<=6          经验>=30
y<0              时间>=13000
物品:diamond>=64
变量:count>=3
距离:100,64,200<=5
```

## 快捷键与命令

| 操作 | 说明 |
|---|---|
| `F8` | 打开 / 关闭界面 |
| `ESC` | 编辑器里 = 放弃本次修改；列表里 = 关闭界面 |
| 项目绑定键 | 编辑器右上角点「绑定按键」→ 按任意键；右键该按钮 = 解除绑定 |
| `/amc gui` | 打开界面 |
| `/amc list` | 列出项目 |
| `/amc run <序号\|项目名>` | 运行项目 |
| `/amc stop` / `/amc status` / `/amc vars` | 停止 / 状态 / 变量表 |
| `/amc npc` / `/amc slot` | 附近 NPC / 鼠标悬停槽位号 |

> 「完成」按钮才会把编辑结果写回配置；直接 ESC 等于没改。

## 已知限制

- 只做**客户端模拟操作**，操作速度受服务端反作弊与延迟影响，建议动作之间留 300ms 以上延迟
- NPC 交易依赖商店界面支持 shift 点击（原版商人面板、大多数 GUI 商店可以）
- 界面按 854×480（GUI 缩放 2）设计，更小的逻辑分辨率会自动切紧凑模式
- 1.12.2 Forge 专用，未适配其他版本
